# Open JA Workbench on iPad

This guide applies after the M5 iPad changes are merged and deployed. The Workbench is currently served to the tailnet at **https://jcs-macbook-air.tail8a223f.ts.net**.

1. On the iPad, open Tailscale and connect to the same tailnet as the M1 Mac.
2. Open **Safari** and visit **https://jcs-macbook-air.tail8a223f.ts.net**. Sign in to Workbench when prompted. If the page does not load, confirm Tailscale is connected and retry the same URL.
3. In Safari, tap **Share** → **Add to Home Screen**. Keep the name **JA Workbench**, then tap **Add**.
4. Open **JA Workbench** from the Home Screen. Confirm the green and gold JA icon appears and the app opens without Safari's address bar.

Keep Tailscale connected whenever using Workbench. The Home Screen icon is a shortcut to the live app; it does not store recruiting data for offline use.

If the icon or standalone view is missing after deployment, remove the old Home Screen shortcut, reload the URL in Safari, and add it again.
